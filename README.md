# NVIDIA Isaac Lab Custom Environments

This repository contains custom environments created for NVIDIA Isaac Lab, a robotics simulation and reinforcement learning platform.

## Available Environments

The following custom environments can be found in the repository:

1. `attempt_12.py` - Script for robot teleoperation 
2. `attempt_7_openvla_check_open_drawer.py` - Environment for testing drawer opening tasks with OpenVLA
3. `attempt_7_openvla_check_pick_cuboid.py` - Environment for testing cuboid picking tasks with OpenVLA
4. `attempt_7_openvla_check_place_objects.py` - Environment for testing object placement tasks with OpenVLA

## Location

All environments are located in: 

`source/standalone/tutorials/06_mattia/`

## Usage

To use any of these environments:

1. Clone this repository
2. Navigate to the appropriate directory
3. Run the desired environment script

## Requirements

- NVIDIA Isaac Lab
